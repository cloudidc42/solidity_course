# หลักสูตร Solidity ครบวงจร: จากศูนย์สู่ระดับโลก

## เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ออกแบบมาเพื่อสอนการพัฒนา Smart Contract ด้วยภาษา Solidity บน Ethereum และ EVM-compatible blockchains ตั้งแต่ระดับเริ่มต้นจนถึงระดับมืออาชีพระดับโลก
